# 五款答题与练习游戏交互对标清单

> 调研日期：2026-11-18。范围：口算碰碰船、汉字拼音找朋友、图形规律侦探、动物分类馆、数学小练本。
> 来源正文/源码和每款游戏映射见 `content-src/research/learning-interactions.json`。本地代码只作差距对照，不计入外部资料数。

## 实读数量与边界

- 本轮实际读取：**20 份唯一资料**；五款游戏各关联20份，共100个映射。共享映射不重复计为全局唯一来源。
- 达到每款至少20份的数量目标。20份中包括同一GCompris项目的不同源码文件、官方页面/手册/API，以及原有4份通用设计文章；因此是20份独立文件或文档，不是20个独立项目。不同来源的证据强度和对各游戏的相关度不同。
- 新增实读源码包括 GCompris 的 Guesscount、Erase、Algorithm、Categorization、LetterInWord、Memory 活动及相关 JS 逻辑。其主要证据分别涉及算式构建、连续触摸擦除、规律补序、分类拖放、字词选择/朗读和翻牌配对；逐条证据、URL、本地对应位置与差距见 JSON。
- 另读取 GCompris 官方学校/分级说明、GNU/KDE 产品页、两份教师/使用手册及 ActivityBase API 页面。通用资料仍为原 Zap Code、Plume Studio、Everyday Psy、OriginUX 四份。
- 抓取边界：GCompris Invent 的 Guesscount QML URL 返回 501，随后改从 GitHub raw 镜像读取同一源码并计入；MemoryCommon.qml 路径返回 404。五个 Godot 文档 URL 只返回目录/截断信息或未显示目标正文，因此未计数。所有失败与排除原因记录在 JSON 的 `failed_or_excluded_retrievals`，未据此摘录结论。未打开的搜索链接均未计入。
- 本地“已实现”判断来自静态代码阅读，未运行游戏、未在平板验证布局与声音，不代表运行验收通过。

## 共通对标结论

| 主题 | 实读资料中的具体做法 | 本地共用答题流程 | 对标判断 |
|---|---|---|---|
| 题面层级 | 题目应突出，选项有足够字号、对比和间距 | 共享舞台显示题目与三个按钮；题面字号按可用尺寸缩放 | 基础结构已具备，极端尺寸和触控仍需设备查看 |
| 答题防连点 | 首次选定后暂时禁用选项 | 规则层仅在 `question` 阶段接受答案，反馈阶段选项禁用 | 静态代码已具备状态锁 |
| 答后反馈 | 即时、温和、视觉可辨；错误后引导正确项 | 正误文案、答案高亮、错项轻摇、答对星星；讲解须手动“下一题” | 已覆盖核心学习节奏 |
| 题型匹配 | 日期、比较、位置、分类应考虑滑块、缩放、地图或拖放等对应操作 | 五款目前统一使用三选一 | 核心产品差距：按各游戏题目目标验证输入方式 |
| 多模态与感官负荷 | 文字、图像、声音组合；声音和动效可控制 | 题目可朗读；共享反馈音/触觉和全局声音设置 | 需在目标平板核验可读性、音量与开关覆盖 |
| 进度与节奏 | 显示当前进度；微动效保持短促；避免无必要时间压力 | 进度题数和里程碑星；无倒计时；题间过渡约 0.12/0.22 秒 | 静态参数与目标一致，实际观感未测 |

## 逐款清单

### 口算碰碰船

- **已有**：三选一、题目朗读、答后正确答案和解释、手动下一题、错题归集、无倒计时；舞台绘制水面与船只进度。
- **差距**：仍只有选择输入。实读资料提出输入方式匹配考察目标，但没有证据表明口算必须改为新操作；应先从现有题目类型挑选少量代表题验证数字拖动/填空是否比三选一更清楚。
- **代码位置**：`quiz_game.gd:164`、`quiz_game.gd:207`、`quiz_stage.gd:388`。

### 汉字拼音找朋友

- **已有**：题目自动朗读和再次听题、三选一、拼音主题视觉、错答后正确项提示与解释。
- **差距**：汉字—拼音关联目前主要通过选择完成；可对照配对或音节拖放，但要确保无需精细拖拽也能完成，并保留点选路径。
- **代码位置**：`quiz_game.gd:197`、`quiz_game.gd:200`、`quiz_stage.gd:402`。

### 图形规律侦探

- **已有**：规律题专属视觉背景，反馈时圈出正确选项，错误反馈温和，手动看完讲解才继续。
- **差距**：仍是三选一；拖动图形补到序列空位可能更直接呈现推理过程，需验证误触、撤销和小尺寸触控。
- **代码位置**：`quiz_game.gd:187`、`quiz_stage.gd:413`、`quiz_stage.gd:267`。

### 动物分类馆

- **已有**：动物主题场景与图片符号，三选一后展示答案和生活知识解释。
- **差距**：栖息地、类别、食性等分类目标可以探索拖入篮子或左右分拣；需要维持点选替代方式，避免只靠颜色区分类别。
- **代码位置**：`quiz_game.gd:191`、`quiz_stage.gd:423`、`quiz_stage.gd:444`。

### 数学小练本

- **已有**：基础/计算/应用/综合页签，题量与星级门槛由 `tuning.json` 管理，错题可单独复习；答题舞台采用练习本视觉。
- **差距**：不同数学内容仍统一三选一；可按题型试做数轴滑块、数量比较或分步操作，但要保留儿童可理解的误差反馈，不能仅因案例文章提到就直接套用。
- **代码位置**：`quiz_game.gd:97`、`quiz_game.gd:193`、`quiz_stage.gd:431`、`tuning.json:118`。

## 优先级建议

1. 先为图形规律和动物分类各挑选少量代表题，验证拖放/分拣是否更贴合题意，并保留三选一点按作为兼容路径。
2. 检查五款在最小目标窗口下的题干换行、按钮命中尺寸、反馈区与下一题按钮是否同时可见；现有代码自适应不等于设备验收。
3. 完成后续外部资料收集时，以每款20–30份实际正文为目标，逐项登记唯一来源、读取证据和适用限制；共享资料只计一次唯一来源。
